Este pacote nao usa irm, iwr, Invoke-RestMethod nem baixa codigo remoto para executar a remocao de IA.
O modulo OtimizacaoTI_AI_Local.ps1 foi escrito para execucao local, com logs, confirmacao forte, backup de registro, ponto de restauracao quando possivel, diagnostico e tarefa pos-update.

Observacao: apps classicos como Paint/Snipping Tool/Notepad extraidos de imagens do Windows nao foram empacotados aqui, pois binarios proprietarios do Windows devem vir de uma fonte licenciada/local do usuario. O submenu de Apps Classicos esta pronto para instalar/registrar payloads locais em payloads/ClassicApps/.
